🏗️ Architecture Flow

1. Browser Frontend: public/index.html + style.css
⬇️ HTTP REST Requests (JSON)
2. REST API Server: Node.js + Express (server.js on port 3000)
⬇️ In-Memory Persistence
3. Data: items array

🧪 REST API Verification

  • GET /items — returns 200 OK with all dishes
  • GET /items/:id — returns dish or 404 Not Found
  • POST /items — adds dish with 201 Created, or 422 on missing name
